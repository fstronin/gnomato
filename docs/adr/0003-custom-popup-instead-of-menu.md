# Кастомный попап по левому клику вместо стандартного меню

Стандартное меню `PanelMenu.Button` — список `PopupBaseMenuItem`; кольцо отсчёта, ряд томатов Set и круглые кнопки в него не помещаются, не переопределяя каждый пункт по отдельности. Поэтому левый клик открывает кастомный попап — подкласс `PopupMenu.PopupMenu`, поставленный индикатору через `setMenu()`: он получает стрелку `BoxPointer`, позиционирование, модальный grab, закрытие по клику мимо и Escape от `PopupMenuManager`, в который `Main.panel.addToStatusArea` регистрирует `indicator.menu`. Стандартное меню уезжает на правый клик (второй `Clutter.ClickGesture` с `required_button: BUTTON_SECONDARY`): контролы Interval — Start/Pause, Skip, Reset — остаются в попапе, а в меню живут данные дня (сегодняшний счёт и сброс счёта) и вход в Preferences.

Цена решения — отход от HIG (от панельной кнопки ожидается обычное меню) и потеря клавиатурной навигации по контролам: `PopupMenuBase._getMenuItems()` фильтрует детей `box` по `instanceof PopupBaseMenuItem`, поэтому кастомные `St`-акторы в стрелочной навигации и фокусе не участвуют. Клавиатурный путь остаётся хоткеями из prefs (назначаются пользователем, по умолчанию пусты) — размен принят сознательно ради вида попапа.

## Considered Options

- **Обычное меню, кольцо внутри пункта.** Отклонено: кольцо и ряд томатов пришлось бы рисовать внутри `PopupBaseMenuItem`, переопределяя отрисовку пункта ради одного popup'а; вёрстка осталась бы меню'шной.
- **Свой `St.Widget`, позиционируемый вручную, со своим `PopupMenuManager`.** Отклонено: пришлось бы повторять то, что `PopupMenu` и менеджер уже дают — стрелку, выравнивание по источнику, модальный grab, закрытие по клику мимо, Escape, взаимоисключение попапов.
- **OSD или отдельное окно.** Отклонено: вне характера продукта — он живёт в панели, а не поверх всего.

## Consequences

`stylesheet.css` становится частью payload расширения: Shell сам грузит его при `enable()` (`extensionSystem._loadExtensionStylesheet`), поэтому правки вида применяются `disable`+`enable`, без новой сессии shell. Это добавляет файл в rsync-исключения dev-цикла, в `build-deb.sh` и в список содержимого каталога расширения в README.
