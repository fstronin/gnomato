# Размер Set фиксируется с началом его первого Interval

Размер Set — настройка (`set-size`), но у него есть момент, с которого он перестаёт применяться к идущему Set: без такого момента правка настройки на ходу меняла бы и ряд томатов в попапе, и то, где заканчивается текущий Set. Решили: Set фиксирует размер, **когда открывается его первый Interval** — то есть пока Set не начат (слот не израсходован и Interval не открыт), значение применяется сразу; как только первый Pomodoro пошёл, правка `set-size` — в том числе во время этого Pomodoro и на паузе — относится к следующему Set. Новое значение берёт следующий Set.

Причина в наблюдаемом: ряд томатов и долгий перерыв не должны съезжать под руками у пользователя. Момент «израсходован первый слот» наступает только в *конце* первого Pomodoro, поэтому правило, привязанное к нему, оставляет окно, в котором правка `set-size` (или восстановление настроек из prefs) перекраивает идущий Set: ряд меняет длину, а Set заканчивается через другое число Pomodoro. Именно это окно и было ошибкой: `setSetSize` смотрел только на `slot === 0`, а весь первый Pomodoro Set проводит именно в нулевом слоте. Размер идущего Set живёт в памяти Timer; перезапуск расширения эту память теряет и берёт значение настройки — тот же размен, что и с длинами идущего Interval.

## Considered Options

- **Фиксировать по первому израсходованному слоту** — отклонено: окно первого Pomodoro тогда перекраивает идущий Set (ошибка, ради которой этот ADR и написан).
- **Хранить размер идущего Set в GSettings** — отклонено: ещё один ключ, который пишется только ради случая, различимого лишь перезапуском шелла; настройка — достаточный запасной вариант, а ряд всё равно перерисовывается из неё.
- **Применять правку только к следующему Set всегда** — отклонено: тогда правка `set-size` перед началом Set (ничего не израсходовано, ничего не идёт) не даёт видимого эффекта, пока не закончится весь Set, и пользователь видит, что настройка «не работает».

## Consequences

`Timer.setSetSize` проверяет два условия (`slot === 0` и отсутствие открытого Interval), а не одно; правило покрыто тремя тестами в `tests/timer.test.js` (первый Pomodoro идёт, первый Pomodoro на паузе, Set ещё не начат) и строкой «Set» в `docs/spec.md`.
